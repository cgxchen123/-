# 比赛能力边界

赛道：算法创新赛｜AI+场景创新

## 推荐叙事

芯造天工不是“让大模型直接设计硬件”，而是让生成式 AI 进入一个需要工程约束、证据和拒绝机制的真实场景。

核心链路：

自然语言需求
→ 结构化需求
→ AI 规划
→ 确定性工程检查
→ Evidence
→ Engineering Gate
→ PASS / REVIEW / BLOCKED

## 不应宣传

- 全自动 PCB Layout / 生产文件
- 全品类 SPICE
- 全品类 Datasheet 参数自动核验
- 量产级验证或认证
- 企业节省多少时间
- 大规模用户已使用
- 商业化收益

没有原始证据就不写数字。
