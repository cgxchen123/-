# v5.4.0

日期：2026-10-07

状态：当前比赛基线。

本版本的核心不是新增一堆页面，而是修复工程可信链上的三个关键问题：

1. 用户明确输入的 24V 不能被模板 12V 默认值覆盖。
2. Evidence 电压必须跟随真实输入事实，而不能写死演示文案。
3. 发布包验证不能依赖开发机目录。

关键回归：
- 24V → 5V → 3.3V
- 12V Evidence → PASS
- 24V Evidence → REVIEW
- 高风险继电器线圈直连 GPIO → BLOCKED

内部验证：83/83 单元测试、发布自检、Fail-Closed 预演、接线文档 64/64、MCU 专项 35/35 等结果见 `docs/TESTING.md`。
